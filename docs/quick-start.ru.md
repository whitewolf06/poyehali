# Быстрый старт

Открой проект в агенте и отправь ему ссылку на Poyehali. Это может быть пустая папка или репозиторий, которым ты уже пользуешься.

> Настрой этот проект по https://github.com/whitewolf06/poyehali. Начни с правил для агента.

Если уже знаешь, что строишь, добавь пару строк. Например, «Это внутренняя админка на Vue и Legato UI. Нужна SPA, API уже есть. Добавь правила и конфиги проверок».

Агент посмотрит на код и документацию, спросит про оставшиеся решения и покажет, какие файлы собирается менять. Если с самого начала нужны только правила, достаточно сообщения выше.

- **Каркас для агента.** После настройки следующий агент сможет открыть `AGENTS.md` и найти там путь к архитектуре, правилам кода и проверкам.
- **Каркас + конфиги.** Попроси этот режим, если нужны ещё настройки линтера, тестов и CI.
- **Каркас + базовое приложение.** Выбери его, если хочешь сразу запустить минимальный интерфейс, API или их связку у себя.

Для нового Vue-проекта есть пресет с [Legato UI](https://github.com/whitewolf06/legato-ui). Если бэкенд нужен отдельно, агент предложит FastAPI на Python или Go. В существующем проекте он начнёт с того стека и тех правил, которые уже действуют.

Если клиент не может прочитать GitHub, дай ему путь к локальной копии Poyehali и попроси начать с [`SKILL.md`](../skills/poyehali/SKILL.md).
